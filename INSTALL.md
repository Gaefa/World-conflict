# Установка

Два способа: скачать готовое приложение (просто поиграть) или запустить из исходников (разработка).

---

## 1. Готовое приложение

### Скачать

Все сборки — на странице [Releases](https://github.com/Gaefa/World-conflict/releases). Бери самый верхний релиз:

| Система | Файл |
|---------|------|
| macOS | `Conflict.Game-*.dmg` |
| Windows | `Conflict.Game-*.exe` |

Сборки собираются автоматически при каждом изменении в `main`, поэтому верхний релиз — всегда свежий код.

### macOS: «Приложение повреждено»

Сборки **не подписаны** сертификатом Apple (это стоит $99/год и не нужно на этапе тестирования), поэтому macOS блокирует запуск и пишет, что приложение повреждено. Оно не повреждено — просто не подписано. Три способа обойти:

**Способ 1 — скрипт из DMG (самый простой)**
1. Открой `.dmg`, перетащи `Conflict.Game` в `Applications`
2. В том же окне DMG дважды кликни `Open Anyway.command`

**Способ 2 — терминал (одна команда)**
```bash
xattr -cr /Applications/Conflict.Game.app
```
После этого приложение открывается обычным двойным кликом.

**Способ 3 — через контекстное меню**

Правой кнопкой на `.app` → «Открыть» → в диалоге ещё раз «Открыть».

### Windows: «SmartScreen защитил ваш компьютер»

Причина та же — нет подписи. Нажми **«Подробнее» → «Выполнить в любом случае»**.

### Что дальше

Запусти приложение → выбери язык → «Одиночная» → название сессии и своё имя → выбери страну на глобусе → «Начать игру».

Сервер и база данных для одиночной игры не нужны — всё крутится внутри приложения.

## 2. Из исходников

### Требования

- **Node.js 20 или новее** ([nodejs.org](https://nodejs.org))
- npm 10+ (идёт вместе с Node)
- Git

PostgreSQL **не требуется** — без переменной `DATABASE_URL` сервер хранит состояние в памяти. Это нормальный режим для разработки и одиночной игры.

### Запуск

```bash
git clone https://github.com/Gaefa/World-conflict.git
cd World-conflict
npm install
npx turbo dev
```

Поднимутся два процесса:
- **веб-клиент** → http://localhost:3000
- **сервер** → http://localhost:3002 (нужен только для LAN/онлайн-режимов)

Открой http://localhost:3000 и играй.

### Полезные команды

```bash
npm run dev:web       # только клиент
npm run dev:server    # только сервер
npm run typecheck     # проверка типов во всех пакетах
npm run lint          # ESLint
npm run build         # продакшен-сборка
```

### С базой данных (опционально)

Нужна только если хочешь, чтобы сессии переживали перезапуск сервера:

```bash
# в apps/server/.env
DATABASE_URL=postgresql://user:password@localhost:5432/conflict
```

```bash
npm run db:push    # создать таблицы
npm run db:seed    # залить стартовые данные стран
```

## 3. Собрать десктоп-приложение самому

```bash
cd apps/desktop
npm run dist:mac     # → DMG для macOS
npm run dist:win     # → EXE для Windows
npm run dist         # оба сразу
```

Готовые файлы появятся в `apps/desktop/dist/`.

Сборка сначала компилирует сервер в один бандл (esbuild) и собирает статический Next.js, затем упаковывает всё в Electron — на выходе автономное приложение, которому не нужен ни Node, ни интернет.

## 4. Игра по сети

### LAN (одна квартира / офис)

1. На машине-хосте запусти приложение или `npx turbo dev`
2. Узнай локальный IP хоста:
   - macOS/Linux: `ipconfig getifaddr en0` или `hostname -I`
   - Windows: `ipconfig` → строка IPv4
3. Хост создаёт сессию в режиме **«Мультиплеер»**
4. Остальные заходят на `http://<IP-хоста>:3000` и подключаются к сессии

В десктоп-версии сервер слушает `0.0.0.0`, так что подключение с других машин работает сразу.

### Онлайн

Клиент ходит на адрес из `NEXT_PUBLIC_API_URL` (по умолчанию `http://localhost:3002`). Чтобы играть через общий сервер, задай при сборке клиента:

```bash
NEXT_PUBLIC_API_URL=https://your-server.example.com npm run build --workspace=apps/web
```

## Проблемы

**`npm install` падает на нативных модулях** — проверь версию Node (`node -v`), нужна 20+.

**Порт 3000 занят** — Next.js сам возьмёт следующий свободный и напишет какой. Порт сервера меняется через `PORT=3005 npm run dev:server`.

**Белый экран после запуска десктоп-приложения** — обычно это заблокированный macOS запуск; см. раздел про Gatekeeper выше.

**Игра идёт, но ничего не происходит** — проверь, не стоит ли пауза (кнопка в шапке) и не закончилась ли сессия победой.
