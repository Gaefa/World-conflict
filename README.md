# Conflict.Game

**Геополитическая стратегия в реальном времени на 3D-глобусе.** Берёшь одну из 30 реальных стран и ведёшь её через экономику, войну, дипломатию и разведку — против 29 стран под управлением ИИ или против живых игроков.

Версия **0.9.2** · [Скачать и установить](INSTALL.md) · [Состояние проекта](STATE.md) · [Ревью пробелов](REVIEW.md) · [Дизайн-документ](DESIGN.md)

## Как это работает

### Время идёт само

Игра не пошаговая. Каждые **10 секунд** проходит тик = **1 месяц** игрового времени: пересчитывается экономика, добываются и потребляются ресурсы, движутся армии, ИИ принимает решения. Чем больше в мире активных войн, тем длиннее тик (до 25 секунд) — чтобы успевать принимать решения, когда их много. Игру можно ставить на паузу.

Ты не «ходишь» — ты отдаёшь распоряжения, а сервер считает последствия.

### Панель действий вместо меню

Внизу экрана — четыре дорожки-домена, всё управление страной в них:

| Дорожка | Что в ней |
|---------|-----------|
| ⚔️ Военные | вербовка, танковые корпуса, объявление войны, вторжение, авиаудары, блокада, ядерный удар |
| 🏦 Экономика | инвестиции, соцпрограммы, налоги, стратегические резервы, игра на ценах, обход санкций |
| 🕊️ Дипломатия | торговые сделки, альянсы, санкции, оружейные сделки, мирные переговоры |
| 🕵️ Разведка | шпионаж, контрразведка, пропаганда, диверсии, кибератаки, перевороты |

На каждой карточке сразу видна цена, а если действие сейчас недоступно — вместо описания написана причина: «не хватает бюджета», «выберите цель на глобусе», «нужно 20 кораблей». Никаких проб и ошибок.

Колоды и случайного добора нет намеренно: действия всегда доступны, как только открыты. Ограничивает только реальное — деньги, влияние, войска, технологии. Глава государства, которому «не выпала карта налогов», — это абсурд, поэтому единственная случайность в игре осталась там, где ей место: в исходах боёв и операций.

**Дорожки растут от технологий.** В каждой есть карточка «Исследования» — она показывает, какая технология следующая и сколько стоит. Изучил «Drone Warfare» — в военной дорожке появился «Рейд дронов». Военная ветка растит военную дорожку, кибер и разведка — дорожку разведки, экономика с инфраструктурой и биотехом — экономическую. Чем дальше по дереву, тем сильнее инструменты: авиаудары, блокады, ковровые бомбардировки, ядерное оружие.

Кому нужны детали — переключатель **«Консоль»** в правом нижнем углу открывает полный интерфейс: шесть вкладок, карта войны с ручным управлением армиями, таблицы ресурсов, дерево технологий, досье разведки.

### Война — это армии на карте

Объявление войны — не абстракция. У армий есть позиция на глобусе, размер, мораль и опыт:

- **Вторжение** отделяет часть резерва в реальный корпус, который выходит из твоей столицы и **марширует к вражеской** (пехота 4°/тик, броня 6°, авиация 15°). Стоит −4 стабильности дома — война бьёт по тылу.
- **По пути** корпус вступает в бой с защитниками, если они в радиусе 3°. Обороняющийся получает бонус 1.2×, потери 10–30%, мораль качается.
- **Оккупация**: армия у вражеской столицы, если там нет защитников, давит страну — −4 стабильности, −2% ВВП за ход.
- **Капитуляция**: при стабильности ≤8 война заканчивается, оккупант забирает **15% ВВП** трофеем.

Армия без денег теряет мораль, разбитая (меньше 100 человек или мораль ≤10) — исчезает с карты. ИИ в войне тоже водит войска: ведёт простаивающие армии на твою столицу и подкрепляет фронт.

### Дипломатия отвечает

ИИ-страны **сами выходят на связь**: предлагают альянсы, торговлю, оружейные сделки — в зависимости от характера (дипломатичный тянется к союзам, экономический к торговле, агрессивный продаёт оружие). Предложения приходят карточками справа с кнопками «Принять / Отклонить», без открытия вкладок. Твои исходящие предложения тоже получают ответ — зелёный или красный тост.

Предложение без ответа протухает через 15 ходов.

### Туман войны

Ты видишь только то, что разведал. Чужая экономика, армия, стабильность — размытые оценки, пока не проведёшь операцию. Есть шпионские операции пяти видов, контрразведка, дезинформация (подсунуть противнику завышенные данные о себе) и досье, которые копятся тик за тиком.

### Ресурсы и цепочки

25+ ресурсов с производством, потреблением и дефицитом. Сырьё перерабатывается в продукцию: руда + уголь → сталь, редкоземельные + медь → электроника → полупроводники. Дефицит бьёт по ВВП, инфляции и стабильности — причём по-разному: нехватка воды и еды рушит стабильность, нехватка нефти — экономику.

Глобальный рынок с ценами, санкции рвут поставки, контрабанда их обходит (с риском), стратегические запасы спасают при блокаде.

### Условия победы

| Победа | Порог |
|--------|-------|
| **Доминирование** | Index of Power ≥ 80 и в 1.5 раза выше второго места |
| **Экономическая** | ВВП > 40% мирового |
| **Дипломатическая** | Союз с 60%+ стран |
| **Технологическая** | 30 исследованных технологий (из 41) |
| **Выживание** | Наивысший Index of Power к концу сессии |

**Index of Power** = ВВП (25%) + военная мощь (25%) + дипломатическое влияние (20%) + технологии (15%) + стабильность (15%).

## Быстрый старт

**Игроку:** скачай готовую сборку для macOS или Windows — [инструкция по установке](INSTALL.md).

**Разработчику:**

```bash
npm install
npx turbo dev     # клиент :3000 + сервер :3002
npm test          # 102 теста
```

Открой http://localhost:3000 → «Одиночная» → введи название сессии и имя → выбери страну → «Начать игру».

Требуется Node.js 20+. База данных не нужна — сервер хранит сессии в памяти. Подробности в [INSTALL.md](INSTALL.md).

## Режимы игры

| Режим | Как работает |
|-------|--------------|
| **Одиночная** | Движок крутится прямо в браузере/приложении, без сервера. Есть сохранения (IndexedDB). |
| **LAN** | Десктоп-приложение поднимает сервер, клиенты подключаются по локальному IP. |
| **Онлайн** | Общий сервер, связь по WebSocket. |

**Мультиплеер:** хост создаёт лобби и отправляет остальным код приглашения из 6 символов. Игроки входят по коду, выбирают свободные страны, хост начинает игру. У каждого игрока две паузы, каждая до минуты.

Языки: русский и английский, переключается на лету.

## Структура проекта

```
apps/
  server/          Fastify + WebSocket + REST (лобби, сессии)
  web/             Next.js клиент: 3D-глобус, панель действий, консольный режим
  desktop/         Electron-обёртка → DMG / EXE
packages/
  shared-types/    Типы + данные: countries.json (30 стран), tech-tree.json (41 технология)
  game-logic/      Чистая логика: экономика, ресурсы, бои, стабильность, разведка, технологии
  game-engine/     Тик, обработка действий, ИИ, условия победы
  game-transport/  WebSocket-слой (общий для сервера и клиента)
  utils/           Гео-утилиты, форматирование
```

Правило разделения: `game-logic` — чистые функции без транспорта, `game-engine` — оркестрация тика поверх них, `game-transport` — доставка. Поэтому движок одинаково гоняется в тестах, в воркере и на сервере.

## Стек

## Баланс правится данными, не кодом

Ключевые числа вынесены в JSON — их можно менять без TypeScript:

- `packages/shared-types/src/countries.json` — стартовые параметры 30 стран
- `packages/shared-types/src/tech-tree.json` — 41 технология, зависимости, эффекты
- `apps/web/src/lib/cards.json` — 32 действия панели: стоимость, требования, условия открытия
