# Состояние проекта

Версия **0.9.2** · обновлено 2026-09-10

Играбельная сборка на плейтесте. Одиночная игра проходится от старта до победы. Мультиплеер проверен двумя живыми клиентами: хост создаёт лобби, остальные входят по коду приглашения, все выбирают страны, хост начинает — гости попадают в ту же партию.

---

## Что готово

### Ядро

- **Тик-движок**: 10 сек = 1 месяц, адаптивная длительность (+3 сек за каждую активную войну, потолок 25 сек), пауза/возобновление, детерминированный RNG с сидом (одинаковый сид + те же действия = одинаковый результат)
- **38 типов действий**: военные операции, дипломатия, экономика, разведка, тайные операции, ресурсы
- **30 стран** с реальными стартовыми параметрами, все живут в мире одновременно
- **Условия победы**: доминирование, экономическая, дипломатическая, технологическая, выживание

### Экономика и ресурсы

- 25+ ресурсов, производство/потребление/дефицит, стратегические запасы
- Цепочки переработки (сырьё → продукция), глобальный рынок с динамическими ценами
- Санкции с эффектом на обе стороны, обход санкций, контрабанда, манипуляция ценами
- Дефициты бьют по ВВП/инфляции/стабильности с разными весами по типу ресурса

### Военная система

- Армии как объекты на глобусе: позиция, размер, мораль, опыт, содержание из бюджета
- Движение к цели со скоростью по типу войск, корректная математика через антимеридиан
- Бои при сближении на 3°, бонус обороны 1.2×, потери и мораль, уничтожение разбитых частей
- **Оккупация → капитуляция**: удержание вражеской столицы без защитников давит страну до капитуляции, победитель забирает 15% ВВП. Войны заканчиваются военным путём, а не только переговорами
- **Вторжение** отделяет реальный корпус из резерва и ведёт его на столицу противника (не мгновенный бросок кубика)
- Авиаудары, блокады, рейды дронов, ядерные удары — стоимость масштабируется по ВВП страны

### Дипломатия

- Двухшаговые предложения: `proposed` → принятие/отклонение, протухание через 15 ходов
- ИИ сам инициирует контакт с игроком (альянсы, торговля, оружейные сделки) с учётом характера и защитой от спама
- Плавающий инбокс входящих предложений и тосты об исходах твоих
- Мирные переговоры, санкции, торговые соглашения с потоками ресурсов

### Разведка

- Туман войны: чужие параметры видны как оценки, точность зависит от разведки
- 5 типов шпионских операций, контрразведка, дезинформация, накопление досье

### Технологии

- 41 технология в ветках с зависимостями, эффекты на статы и разблокировку действий
- Исследования открывают карты в соответствующих дорожках

### Интерфейс

- **Панель действий (по умолчанию)**: 4 домена-дорожки, 32 действия, всё доступно сразу без колоды и добора. На карточке видна цена; недоступное блокируется с указанием причины
- **Исследования прямо в дорожках**: карточка показывает следующую технологию и её цену, а изученное открывает новые действия в этой же дорожке
- **Консольный режим**: 6 вкладок, карта войны с ручным управлением армиями, таблицы ресурсов, дерево технологий — переключается тумблером
- **Лобби мультиплеера**: код приглашения из 6 символов, список игроков с выбранными странами, занятые страны недоступны, хост начинает, гости входят в игру сами
- 3D-глобус с подсветкой войн/союзов/санкций, карта войны с армиями
- Лента событий, таблица лидеров, панель целей, таймер хода, тосты результатов
- Локализация RU/EN, включая описания эффектов и событий

### Инфраструктура

- Три режима: одиночная (движок в клиенте), LAN, онлайн (WebSocket)
- **Серверная валидация**: границы всех числовых полей действия, лимит 12 действий на игрока за тик
- **Места игроков по секретному токену**: в лобби входят только по коду, create/join выдают токен, без него не войти в WebSocket и не вызвать REST. Страна берётся только из состояния игры, `GET /state` отдаёт затуманенный вид своего места, старт — только у хоста, страна меняется только в лобби
- **Живое лобби**: игроки опрашивают его раз в 2 с; кто пропал на 30 с — выбывает и не блокирует старт, без хоста лобби закрывается
- **Паузы в мультиплеере**: по 2 на игрока, каждая до 60 с; досрочно снять может только поставивший. В одиночной игре пауза без ограничений
- Сохранения в IndexedDB (одиночная игра), рестарт после победы
- Автопереподключение WebSocket с нарастающей задержкой (1с → 15с)
- Автосборка DMG/EXE в GitHub Actions на каждый пуш в `main`
- Сервер хранит всё в памяти, базы данных нет

## Известные ограничения

Не баги, а осознанные решения текущего этапа:

**Перезагрузка страницы выкидывает из мультиплеерной партии.** Токен места живёт в памяти вкладки: обрыв связи переживается автопереподключением, а перезагрузка — нет. Сессии тоже живут только пока работает сервер.

**Нет рейтинга и матчмейкинга.** Играть можно с теми, кому отправил код. Для игр с незнакомцами нужны публичный сервер, аккаунты и хранение рейтинга.

**Локализация эффектов работает по словарю строк.** Движок отдаёт английские описания, клиент переводит их словарём и регулярками (`effectLocalizer.ts`). Изменится формулировка в движке — перевод молча отвалится на английский. Правильная глубина — структурированные эффекты `{stat, delta}` из движка.

**Исходы предложений детектятся диффом статусов на клиенте.** При переподключении в мультиплеере клиент может не увидеть переход `proposed → active` и не показать тост. В одиночной игре не проявляется.

**Часть действий доступна только в консоли**: ручное управление армиями на карте войны, контрпредложения по торговле, освобождение захваченных активов, ползунок бюджета разведки, контрабанда с выбором маршрута. Это те действия, которым нужен свой экран, а не одна кнопка.

**Спроектировано, но не построено** (из DESIGN.md): голосования в ООН, ультиматумы, гуманитарная и экономическая помощь, военные базы у союзников, военное положение, уникальные traits стран.

## Проверка качества

```bash
npm test         # 107 тестов
npm run typecheck
npm run lint
```

Тесты покрывают чистую логику: движение и бои армий, оккупацию с капитуляцией, содержание войск, ресурсный тик (включая регрессию на неразрастающееся потребление), Index of Power, все пять условий победы, вторжение с отделением корпуса, протухание и прунинг отношений, серверную валидацию действий, каталог панели действий и сверку его цен с движком. Мультиплеер проверяется на настоящем сервере с WS-клиентами: вход по коду, вид лобби, выбывание пропавших и закрытие лобби без хоста, места по токену, страна только своего места, туман в `GET /state`, старт у хоста, лимит и таймер пауз, реконнект.

Чего тестами не покрыто: React-компоненты (нужен jsdom). Плюс живая проверка сессии в браузере перед релизом.
